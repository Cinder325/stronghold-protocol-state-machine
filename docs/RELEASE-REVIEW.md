浏览器接入和座位恢复检查使用原版的测试Match替身隔离生命周期；四Worker开局和通关统计使用真实Match。界面检查通过不代表替身模拟了整局战斗。

最终真实四Worker整局另测开发种子111000：原版0.3.3最高难度，第14、15轮均通关，运行、模拟、元效果、调度与规则审计错误为0。萨尔贡1–15轮准备时余款均为0，14/15轮原生整备结算前后也为0。等待Worker时暂停虚拟整备时钟，所以这只验证功能链路，不作为实时性能或正式十局胜率；较早候选同种子曾失败，不能因构筑及并发顺序不同而视为严格配对改进证据。

萨尔贡尾部资金收尾及合法容量修复通过两版各6项原生专项回归：13金币被用于真实装备和叠层，核心及三投资人保留，满手不能购买装备的原规则不变；不兼容法穿携带者、核心转职物、无可买目标及动作预算不足时不会无效丢弃信标。最终Worker样本的萨尔贡主循环已花完预算，尾部修复由受控回归单独覆盖。各路线仍可能有少量保守冻结余款或其它决策不足，不声明全局资金最优。

首次发行保留原作者说明及GPL全文，已显著标注复制代码的修改日期。供应商历史清单记录原始文件；安装器使用本发行清单校验修改后的文件。图像只引用宿主已有标识，不包含素材文件。

发布审计扫描所有源文件和文件名，拒绝凭据、私人绝对路径、个人设备标识、个人录制、依赖和模型数据等内容。额外私人匹配词表与详细开发日志置于发布树外。提交前还会检查暂存内容及Git作者身份；自动扫描不是对所有可能隐私形式的绝对证明。

资金修复后策略的完整十局：第14轮9/10通过，第15轮6/10通过（进入第15轮9局，其中6局通过）。全部十局的运行、模拟、元效果、调度与规则审计错误为0，各局安装清单、评估器与宿主源码摘要一致。全部盟约、逐路线层数、失败局及样本数见README和`benchmarks/abyss-v0.3.3.json`。此前候选中断的六局没有混入统计。该统计按公开禁位条件筛选，不能作为未筛选开局或任意操作速度的胜率保证。

十局与真实Worker整局完成后，新增了可选择并记忆的禁位设置，未重跑十局。发行清单摘要因此改变，历史结果不改写；213个策略、执行及供应商载荷未变，三个设置入口载荷修改、一个纯浏览器记忆模块新增。原抽取与关闭行为的比对及精确差异见`benchmarks/release-equivalence.json`。最终设置通过两版实际浏览器关闭、刷新、换房间、恢复默认和四AI开局核验；同时修正0.3.1房间操作函数无成功返回值造成的记忆未保存问题。

未覆盖：全部地图/禁位/策略被占用组合、任意第三方玩法插件、每种操作速度、多房间长期负载、所有上游回归和官方游戏等价性。本版不会声明完美兼容或保证通关。后续版本应以独立复现和对照测试继续改进。
